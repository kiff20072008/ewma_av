# EWMA-AV: код и данные к статье

Исходные тексты и сценарии воспроизведения всех результатов статьи
Резников М. Б., Сараджишвили С. Э. «Обнаружение аномалий в нестационарном
трафике сети образовательного учреждения адаптивным экспоненциальным
сглаживанием с онлайн-оценкой дисперсии» (Вестник ТОГУ).

Номера формул, таблиц и рисунков ниже — по статье.

## Состав

```
ewma_av/detectors.py     предлагаемая схема (EwmaAV) и методы сравнения:
                         σ-правило, медиана и MAD, EWMA, AEWMA (Капицци —
                         Мазаротто), CUSUM, Хольт — Уинтерс (вариант Брутлага)
ewma_av/metrics.py       калибровка порога, F-мера, AUC-ROC, AUC-PR, атаки
ewma_av/ugr16_minute.py  загрузка одноминутных данных UGR'16 (вариант UGR16v1)
ewma_av/boun.py          счётчики по секундам и разметка набора BOUN DDoS
ewma_av/datasets.py      суточный и недельный профили
ewma_av/generators.py    генератор синтетического ряда (граница применимости)

run_ugr16.py      нестационарность (рис. 1), сравнение методов (табл. 2),
                  доверительные интервалы, устойчивость к параметрам (табл. 3)
run_boun.py       сравнение на трафике кампусной сети (табл. 4)
run_ablation.py   вклад приостановки и пересчёта (5)
run_synthetic.py  граница применимости: медленно нарастающая аномалия
check_theory.py   проверка лемм 1–3 и формулы (5) методом Монте-Карло
bench.py          замер скорости (отсчётов в секунду)
make_figures.py   рис. 1 и 2 (PNG/JPG 300 dpi) и их данные в Excel

results_*/        полученные таблицы (CSV, JSON); figures/ — рисунки
```

```bash
pip install numpy scipy pandas scikit-learn statsmodels matplotlib openpyxl
```

## Данные

**UGR'16** (Maciá-Fernández и др., Computers & Security, 2018) — одноминутная
агрегация авторов набора, вариант UGR16v1 (Camacho, Rodríguez-Gómez, Data,
2025):

```bash
git clone --depth 1 https://github.com/josecamachop/UGR16_FeatureData.git ugr16
```

**BOUN DDoS** (Erhan, Anarım, Data in Brief, 2020) — файлы
`BOUN_TCP_Anon.csv` и `BOUN_UDP_Anon.csv` из публикации набора. Посекундные
счётчики, полученные из них, уже лежат в `results_boun/counters_*.csv`,
поэтому для повторения расчётов исходные файлы (около 1,8 ГБ) не нужны.

## Воспроизведение

```bash
python check_theory.py > results_theory.txt               # леммы 1–3
python run_ugr16.py --repo ugr16 --out results_ugr16      # табл. 2, 3; ~10 мин
python run_boun.py --counters results_boun --out results_boun   # табл. 4
#   или из исходных CSV: python run_boun.py --dir <папка с CSV> --out results_boun
python run_ablation.py --repo ugr16 --boun results_boun   # вклад компонентов
python run_synthetic.py --runs 30                         # граница применимости
python make_figures.py --ugr ugr16 --boun results_boun --out figures
python bench.py                                           # скорость
```

## Протокол (кратко)

* UGR'16: контролируется число потоков в минуту на порт 80; аномальная
  минута — хотя бы один поток атаки «отказ в обслуживании». Порог каждого
  метода — квантиль его статистики на участке 10–26.08.2016 (внесённых атак
  нет), превышаемый в 0,2 % отсчётов; показатели — на участке
  28.07–09.08.2016 без первых 240 мин. 95 % доверительные интервалы —
  бутстрэп по суткам, 2000 повторений.
* BOUN: число пакетов SYN без ACK и число UDP-пакетов в секунду по всей
  магистрали; разогрев 60 с; порог — по нормальным отсчётам той же записи
  на долю 0,01; трёхсекундные интервалы после атак исключены.
* Хольт — Уинтерс оценивается по самому длинному непрерывному участку
  обучающей части UGR'16; остальные методы обучающую выборку не используют.
